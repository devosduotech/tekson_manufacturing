# v15.2.0 Manufacturing Intelligence - Strategy Change

## Decision: Use Frappe Insights Instead of Custom Dashboards

**Date**: August 12, 2026
**Status**: ✅ Approved

---

## What Changed

### Original Plan (Abandoned)
- Custom JavaScript dashboards (`planner_dashboard.js`, `stores_dashboard.js`)
- Custom Query Reports (12+ reports)
- Manual chart rendering with Frappe UI components
- Estimated: 40-60 hours development

### New Approach (Adopted)
- **Frappe Insights** for all dashboards and visualization
- **Tekson analytics layer** for complex business logic only
- Query Builder for simple metrics
- Python APIs for derived manufacturing intelligence
- Estimated: 8-12 hours configuration

---

## Why Frappe Insights?

### Advantages
✅ **Professional Charts** - Better aesthetics out of the box
✅ **Faster Development** - No custom JS, visual query builder
✅ **Customer Configurable** - Each customer can customize their dashboards
✅ **Built-in Filters** - Dashboard-wide filters work automatically
✅ **Drill-down** - Click charts to see underlying data
✅ **Role-based Access** - Insights has built-in permissions
✅ **Less Maintenance** - No custom dashboard code to maintain
✅ **Scalable** - Insights handles large datasets efficiently

### What We Keep
✅ **Analytics Layer** - For complex Tekson business logic
✅ **Python APIs** - `planner_kpis`, `planner_exceptions`, `planner_workload`, `stores_kpis`
✅ **Frozen Architecture** - Intelligence layer still read-only
✅ **Business Rules** - Material Readiness, Dependency Waiting, Production Readiness


## Frozen Principles (Still Apply)

✅ **Intelligence is Read-Only** - Dashboards don't execute transactions
✅ **Answers 4 Questions** - What? Why? Where? Next?
✅ **Separation of Concerns** - Planner ≠ Stores (different roles)
✅ **Complex Logic in App** - Material Readiness, Dependencies in Python
✅ **Simple Metrics in BI** - Counts, sums, groups in Insights

## Migration Path

If you have the custom dashboard code from earlier attempts:
- **Keep** the analytics Python files (`intelligence/analytics/`)
- **Delete** the dashboard page folders (`page/planner_dashboard/`, `page/stores_dashboard/`)
- **Use** Frappe Insights for UI

The branch `v15.2.0-clean` already has this cleaned up.
